## 3. รูปแบบผลลัพธ์ที่ต้องการ (คอลัมน์ เรียงตามลำดับนี้)
- **order** — ลำดับวิชา จากคอลัมน์ "ลำดับ" ถ้าวิชาหนึ่งสอบพร้อมกันหลายห้อง แถวที่ 2 เป็นต้นไปของวิชานั้นในไฟล์ต้นฉบับจะว่าง ต้องเติมค่าจากแถวแรกของวิชานั้นให้ครบ (forward fill)
- **subj** — รหัสวิชา + ชื่อวิชา จากคอลัมน์ "วิชา" ต้อง forward fill เช่นเดียวกับ order
- **sec** — กลุ่มเรียน จากคอลัมน์ "กลุ่ม"
- **st_year** — ชั้นปี จากคอลัมน์ "ชั้นปี"
- **st_max** — จำนวนนักศึกษาทั้งหมดในกลุ่ม จากคอลัมน์ "นศ."
- **ex_dur** — ช่วงเวลาสอบ จากคอลัมน์ "เวลา" เช่น 09:30:00 - 12:30:00
- **teacher_str** — รายชื่อผู้สอนตามที่ปรากฏในไฟล์ต้นฉบับ (คำนำหน้าตำแหน่งวิชาการครบ คั่นด้วย ,) จากคอลัมน์ "ผู้สอน"
- **building** — อาคารที่สอบ จากคอลัมน์ "อาคาร"
- **room** — ห้องสอบ จากคอลัมน์ "ห้อง"
- **note** — จำนวนนักศึกษาที่สอบจริง/ที่นั่งในห้องนั้น เช่น 36/36 จากคอลัมน์ "หมายเหตุ"
- **ex_date** — วันที่สอบ รูปแบบ YYYY-MM-DD (ปี ค.ศ.) ดึงจากข้อความหัวรายงาน "วันสอบ ..." (มีบอกวันที่แบบ พ.ศ. และเดือนย่อภาษาไทย ต้องแปลงเป็น ค.ศ. และเลขเดือน)
- **code4** — รหัสวิชา 4 หลักแรก (ตัวเลข) ตัด 4 ตัวแรกของรหัสวิชาใน subj
- **ex_time** — ชั่วโมงเริ่มสอบ (ตัวเลข) ดึงชั่วโมงเริ่มจาก ex_dur
- **st_num** — จำนวนนักศึกษาที่สอบจริงในห้องนั้น (ตัวเลข) คือตัวเลขก่อนเครื่องหมาย / ใน note ถ้าไม่มีห้องสอบ/ไม่มีค่า ให้เป็น 0
- **ex_dt** — วันเวลาสอบแบบย่อ รวมไว้ใช้ group/sort คือ - ex_date + เว้นวรรค + ex_time เช่น 2026-03-19 13
- **teachers** — รายชื่อผู้สอน ตัดคำนำหน้าตำแหน่งวิชาการออก (เช่น ผศ., ดร., รศ., ผศ. ดร., รศ. ดร., ศ., อ. ฯลฯ) และคั่นหลายคนด้วย ; แทน , ประมวลผลจาก teacher_str

ให้นักศึกษาเปิดไฟล์ example-result.csv ประกอบ เพื่อดูตัวอย่างค่าจริงของแต่ละคอลัมน์ (เช่น การแปลงชื่อผู้สอนหลายคน หรือกรณีที่ไม่มีห้องสอบ)

## 4. ประเด็นที่ต้องระวัง (ไฟล์ต้นฉบับไม่ใช่ตารางที่สะอาด)

- ไฟล์ Excel มีแถวหัวรายงาน (ชื่อสถาบัน, ชื่อรายงาน, ภาคเรียน, วันสอบ) อยู่ด้านบนก่อนถึงหัวตารางจริง ต้องข้ามให้ถูก
- วิชาที่สอบพร้อมกันหลายห้องจะถูกแยกเป็นหลายแถวในไฟล์ต้นฉบับ โดยคอลัมน์ "ลำดับ" และ "วิชา" จะว่างในแถวที่ 2 เป็นต้นไปของวิชานั้น ทุกแถวที่แยกห้องต้องยังอยู่เป็นคนละแถวใน DataFrame ผลลัพธ์ (ห้ามรวมเป็นแถวเดียว) แต่ต้องเติมค่า order/subj ให้ครบ
- บางกลุ่มมีผู้สอนหลายคนคั่นด้วย , ในคอลัมน์เดียว ต้องแยกและตัดคำนำหน้าตำแหน่งวิชาการออกให้ถูกต้อง (สังเกตว่าบางคำนำหน้าเป็นคำผสม เช่น "รศ. ดร." หรือ "ผศ. ดร.")
- อาจมีชื่อผู้สอนต่างชาติที่ไม่มีคำนำหน้าภาษาไทย ต้องจัดการไม่ให้ชื่อผิดเพี้ยน
- วันที่สอบอยู่ในข้อความอิสระ (ไม่ใช่ cell แยกเป็น field) และเป็น พ.ศ. + เดือนย่อภาษาไทย ต้องแปลงให้ถูกต้องเป็นวันที่ ค.ศ. รูปแบบ ISO
- บางแถวอาจไม่มีอาคาร/ห้อง/หมายเหตุ (เช่น ยังไม่ได้จัดห้องสอบ) ให้จัดการค่าว่างอย่างเหมาะสม (ไม่ error และ st_num เป็น 0)

- จัดการ data type ให้เหมาะสม (ตัวเลขเป็นตัวเลข ไม่ใช่ string) ตามตัวอย่างใน example-result.csv
- เขียนโค้ดให้อ่านง่าย แบ่งเป็นฟังก์ชันย่อยได้ตามความเหมาะสม (เช่น ฟังก์ชันแยกทำความสะอาดชื่อผู้สอน, ฟังก์ชันแปลงวันที่ไทยเป็น ISO)
